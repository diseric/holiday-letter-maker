# NoelForge 3D — Holiday Lettering & Ornament STL Studio

Generate custom 3D-printable Christmas letters, connected script holiday nameplates, individual monogram ornaments, backing plaques, festive 3D accents (Santa hat, snowflakes, holly, North star, reindeer antlers), and customizable hanging hoops for string/ribbon — with instant Binary & ASCII **STL** export in exact millimeter (`mm`) units.

## Live App
Published via GitHub Pages: **https://diseric.github.io/holiday-letter-maker/**

## Local Usage
```bash
npm install
npm start
```
Then open `http://localhost:3456`.
